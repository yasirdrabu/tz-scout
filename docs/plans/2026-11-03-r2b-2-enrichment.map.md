## 16. Pitfalls
1. Everything in the section-1 checklist, esp. bootstrap.sql + bootstrap-workspace.sql grants, db-router regex, rls-catalog, migrate.test; RLS policy is manual SQL.
2. Handler throws roll back the job tx (state writes lost). Write `running`/`started_at` and failure status either in own committed tx, or return normally after recording the failed state; only rethrow for retry (`timeout`, `unknown`, `rate_limited`) and cap waits.
3. Credits cost on rate-limit/failed calls: gateway counts 0 credits for failures; paid partial work must `settle` each call separately, so do one `gateway.call` per provider operation with `unit:'credits', units: <worst case>` and `measure` for actual.
4. Reserve is per call, but estimate pre-check `checkCap` is read-only and racy: a request can still hit `blocked_by_cap` mid-run => catch `isCapWait` per call: stop, submit what was found, mark `partial`; only rethrow when nothing was done yet.
5. Mid-run partial results must be submitted BEFORE failing the request (spec); use a savepoint-safe order: submit arrival (inline) -> update request -> rethrow/return.
6. Intake sender ctx needs `dataLimit:{kind:'all'}` (own_source 404s a target). Vendor source daily arrival cap (500) and status (`paused`/`archived` => 403) can fail the submit.
7. Source feedback fan-out (section 13): do not use `recordFeedback` for declines.
8. `redactSummary` drops any key containing "key"/"email"/"token": do not name summary fields `roleKeys` or `emailReveal` expecting them in call_log.
9. `ensureConnection` auto-creates a connection row; calling gateway for apollo before any setup works in mock (adapter must be registered) - but with no adapter registered it is 501 `adapter-missing`.
10. Event names exactly 3 parts; two-word entities need `_`. `enrichment.request.*` fine.
11. Routes: `routes.ts` is order-sensitive and hand-edited; test counts files.
12. Money: no currency/price per credit anywhere in code; tenant currency from `tenantSummary(ctx)` (`tenancy/index.ts`, `{currency,timezone}`); estimate text "Up to 6 credits, about $0.60" needs a cents-per-credit source.
13. Dev `DEV_KEY_SCOPES` and e2e fixtures need `enrichment:request` if a dev agent flags.
14. The ESLint `ADMIN_DB_ALLOWED` list: only add if a platform-wide job needs `mapWorkspaces`; the expiry job is per-tenant via schedule so it does not.
