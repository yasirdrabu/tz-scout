## 9. API mismatches the UI will trip on
1. Template GET steps include `id, template_id, template_version` (+ `order`) but `PATCH/POST /playbooks` bodies are `z.strictObject` per step (`src/http/routes/v1/playbooks/schemas.ts:4-15`, step allows only `order, day, channel, owner_role, title, detail, target_buying_roles, crm_task, subject, body`). Fix in UI: map steps to that whitelist in the form's `valuesOf/bodyOf` (do not send the GET object back). Alternative API fix: `.strip` unknown step keys; recommend UI mapping (surgical).
2. List `steps` is a COUNT and detail `steps` an ARRAY (same name). Detail also has `step_count`, `steps_version`; `days/channels/runs_on/running` describe the CURRENT version even for `?version=n`. Type them as two types.
