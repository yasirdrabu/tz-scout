# CLAUDE.md

## Think Before Coding
- State your assumptions explicitly before writing code.
- Surface trade-offs and alternative approaches briefly.
- Ask clarifying questions if the requirements or scope are uncertain.

## Simplicity First
- Write the minimum amount of code needed to solve the problem.
- Do not add speculative features, unused abstractions, or future-proofing unless asked.

## Surgical Changes
- Touch only the files and code necessary to complete the task.
- Match the existing code style, naming conventions, and patterns.
- Do not refactor unrelated code or files.

## Goal-Driven Execution
- Define verifiable success criteria before starting.
- Run and loop tests until they pass.
- Break multi-step tasks down into explicit, checkable plans.
